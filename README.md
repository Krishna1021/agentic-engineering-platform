# Agentic Engineering Platform

A requirements-first engineering workflow service built with Java 17, Spring Boot,
Gradle and PostgreSQL. An existing application repository is optional.

The platform coordinates analysis, design, implementation, testing, documentation,
validation and human review using an explicit dependency graph. Agents propose
artifacts; application policy owns execution and state transitions.

See [plan.md](plan.md) for delivery scope. Setup, API and verification instructions
are added alongside their implementation in subsequent commits.
